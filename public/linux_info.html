## Curriculum

10 modules, 25 classes, every one hands-on

Each class lists the official RHCSA objectives it covers and the lab you complete before you leave. Open a module to see its classes.

Module 1 Essential toolsClasses 1–4 +
Class 01

Orientation, lab setup and the shell

Objectives coveredAccess a shell prompt and issue commands with correct syntax. Locate, read and use system documentation: man, info, /usr/share/doc.
Hands-on labLog in to the lab system; use man -k and /usr/share/doc to answer questions about unfamiliar commands.
Class 02

Files, directories and links

Objectives coveredCreate, delete, copy and move files and directories. Create and edit text files. Create hard and soft links.
Hands-on labBuild a project directory tree in vim-edited files, then create and test hard and soft links.
Class 03

Redirection, pipes and grep

Objectives coveredUse input-output redirection (>, >>, |, 2>). Use grep and regular expressions to analyze text.
Hands-on labFilter /etc/passwd and log files with grep and regex; save matching output and errors to separate files.
Class 04

Archives, SSH and switching users

Objectives coveredArchive, compress, unpack and uncompress with tar, gzip and bzip2. Access remote systems using SSH. Log in and switch users in multi-user targets. Securely transfer files between systems.
Hands-on labArchive /etc with each compression type, copy it to a second server with scp, and extract it there.
Module 2 Users, groups and permissionsClasses 5–7 +
Class 05

Local user accounts

Objectives coveredCreate, delete and modify local user accounts. Change passwords and adjust password aging.
Hands-on labCreate users with set UIDs, shells and home directories; apply password expiry rules with chage.
Class 06

Groups and privileged access

Objectives coveredCreate, delete and modify local groups and group memberships. Configure privileged access.
Hands-on labBuild team groups; give one group full sudo and another limited sudo rights.
Class 07

File permissions

Objectives coveredList, set and change standard ugo/rwx permissions. Manage default file permissions. Diagnose and correct file permission problems.
Hands-on labFix a set of broken permission scenarios; set umask for a user so new files get the right defaults.
Module 3 Managing softwareClasses 8–9 +
Class 08

RPM repositories and dnf

Objectives coveredConfigure access to RPM repositories. Install and remove RPM packages. Install and update packages from Red Hat CDN, a remote repository or the local file system.
Hands-on labConfigure BaseOS and AppStream repos from a given URL; install, update and remove packages, including a local .rpm file.
Class 09

Flatpak + Modules 1–3 checkpoint

Objectives coveredConfigure access to Flatpak repositories. Install and remove Flatpak packages.
Hands-on labAdd a Flatpak remote and install and remove an app. Then complete a timed checkpoint lab covering classes 1–8.
Module 4 Shell scriptingClasses 10–11 +
Class 10

Script inputs and conditions

Objectives coveredConditionally execute code (if, test, []). Process script inputs ($1, $2). Process the output of shell commands within a script.
Hands-on labWrite a script that takes a username as $1, checks whether the user exists and prints their details.
Class 11

Loops and real scripts

Objectives coveredUse looping constructs (for, etc.) to process file and command-line input.
Hands-on labWrite a script that reads a list of names from a file and creates each user, skipping ones that already exist.
Module 5 Operating running systemsClasses 12–15 +
Class 12

Boot, shutdown and targets

Objectives coveredBoot, reboot and shut down a system normally. Boot systems into different targets manually. Configure systems to boot into a specific target automatically.
Hands-on labSwitch between graphical and multi-user targets, then set the default target.
Class 13

Boot recovery and the bootloader

Objectives coveredInterrupt the boot process to gain access to a system. Modify the system bootloader.
Hands-on labReset a forgotten root password from the boot menu; change kernel boot arguments persistently.
Class 14

Processes and performance

Objectives coveredIdentify CPU/memory-intensive processes and kill processes. Adjust process scheduling. Manage tuning profiles.
Hands-on labFind and stop a runaway process, change process priority with nice and renice, and apply a tuned profile.
Class 15

Logs, journals and time

Objectives coveredLocate and interpret system log files and journals. Preserve system journals. Configure time service clients.
Hands-on labTrace a failed login in the journal, make the journal persistent across reboots, and point chrony at a given time server.
Module 6 Services and schedulingClass 16 +
Class 16

Services and scheduled tasks

Objectives coveredStart, stop and check the status of network services. Start and stop services and configure them to start at boot. Schedule tasks using at, cron and systemd timer units.
Hands-on labEnable a web service at boot, then schedule the same backup job three ways: at, cron and a systemd timer.
Module 7 Storage and file systemsClasses 17–19 +
Class 17

Partitions and file systems

Objectives coveredList, create and delete partitions on GPT disks. Create, mount, unmount and use VFAT, ext4 and XFS file systems. Configure systems to mount file systems at boot by UUID or label.
Hands-on labPartition a new disk, format one partition of each type and mount them permanently in /etc/fstab by UUID and by label.
Class 18

LVM and swap

Objectives coveredCreate and remove physical volumes. Assign physical volumes to volume groups. Create and delete logical volumes. Extend existing logical volumes. Add new partitions, logical volumes and swap non-destructively.
Hands-on labBuild a volume group and logical volume, extend it together with its file system, and add swap without touching existing data.
Class 19

NFS and autofs

Objectives coveredMount and unmount network file systems using NFS. Configure autofs.
Hands-on labMount an NFS export manually and at boot, then configure autofs to mount user home directories on demand.
Module 8 NetworkingClass 20 +
Class 20

Network configuration

Objectives coveredConfigure IPv4 and IPv6 addresses. Configure hostname resolution. Configure network services to start automatically at boot.
Hands-on labSet static IPv4 and IPv6 addresses with nmcli, set the hostname and DNS, and confirm the connection comes up after a reboot.
Module 9 SecurityClasses 21–23 +
Class 21

firewalld

Objectives coveredRestrict network access using firewalld and firewall-cmd. Configure firewall settings using firewall-cmd/firewalld.
Hands-on labOpen a service and a custom port permanently, block the rest, and confirm the result from a second machine.
Class 22

SSH keys and SELinux basics

Objectives coveredConfigure key-based authentication for SSH. Set enforcing and permissive modes for SELinux. List and identify SELinux file and process contexts.
Hands-on labSet up password-less SSH between two servers; switch SELinux modes and inspect contexts with ls -Z and ps -Z.
Class 23

SELinux in practice

Objectives coveredRestore default file contexts. Manage SELinux port labels. Use Boolean settings to modify system SELinux settings.
Hands-on labMake a web server work from a custom directory and a custom port with SELinux enforcing, using restorecon, semanage and booleans.
Module 10 Exam preparationClasses 24–25 +
Class 24–25

Mock exams and final review

Objectives coveredAll RHCSA objectives from Modules 1–9, practised under exam conditions.
Hands-on labTimed, exam-style practice on fresh RHEL 9 systems, followed by a review of weak areas and exam-day strategy.
