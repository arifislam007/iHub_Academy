
  # Sombhabona iHub

  This is a code bundle for Sombhabona iHub. The original project is available at https://www.figma.com/design/Q2WWzgg96k0vZgkvCVQaAV/Skill-Development-Academy.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Docker Compose

  Run `docker compose up --build` to build the site and serve it at http://localhost:8080.
